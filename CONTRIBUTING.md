# Contributing to JourneyHelp

JourneyHelp is an experimental portfolio project. Contributions should improve the end-to-end user experience, answer grounding, reliability, accessibility, or security.

## Principles

- Keep changes small and testable.
- Do not commit secrets, real customer data, private account data, or raw audio.
- Do not invent sources or display placeholder citations as real evidence.
- Add or update tests for behavior changes.
- Document known limitations and evaluation results honestly.
- Keep provider-specific integrations behind small interfaces without over-engineering.

## Suggested workflow

1. Open an issue describing the problem or proposal.
2. Agree on the expected behavior and acceptance criteria.
3. Make a focused change.
4. Run the relevant tests and checks.
5. Update documentation when API contracts or product behavior change.

## Safety

The automotive demo is informational only. Contributions must not imply that JourneyHelp can diagnose faults, replace the official manual, or control a vehicle. Banking examples must use synthetic or public product information unless a properly authorized integration is explicitly designed and reviewed.
